# sandbox

Experimental area for rapid prototyping. Contents are not part of the core package API but capture ideas that may later migrate into production modules.

## Current Items

- `collabolative_filtering.ipynb` – Notebook exploring collaborative filtering approaches for recommendation problems.
- `online_collabolative_filtering.py` – Script version used for quick iteration outside notebooks.

## Guidelines

- Keep experiments self-contained and document assumptions inline.
- Move mature code into the appropriate package directory once stabilized.
- Avoid committing large datasets; reference external storage instead.
