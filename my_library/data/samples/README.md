# samples

Curated toy datasets bundled with the library. Files are stored as CSV and used for unit tests, documentation examples, and validation dry runs.

- `classification/` – Multiclass and binary datasets such as Iris, Breast Cancer, and Titanic.
- `regression/` – Regression datasets such as Diabetes and synthetic targets.

The loader function `my_library.utils.data_loader.load_sample_data` resolves paths to these files automatically.
